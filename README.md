# Yuno assets

الأصول فقط (مجسمات glb/fbx، صور، صوتيات، أنيميشن). الكود في مشروع منفصل.
المسارات هنا **نفس مسارات المشروع (res://)**: انسخ محتوى هذا الريبو فوق مجلد مشروع Yuno فيرجع المشروع كامل.

## الهيكل
- assets/map ........ مدينة ومباني
- assets/animations . أنيميشن الشخصيات
- assets/characters . assets/character . assets/npc ... شخصيات
- assets/weapons .... أسلحة
- assets/stickers ... ملصقات السيارات
- vehicles/ ......... مجسمات السيارات والمرور والدرون (bmw_m4, toyota_gr_supra, traffic, drone)
- audio/ ............ أصوات (car, sfx)
- ui/icons .......... أيقونات الواجهة
- garage/ ........... مجسم الكراج

## للذكاء الاصطناعي
نزّل الريبو (Code ← Download ZIP) وافرد محتواه فوق مجلد المشروع، بنفس المسارات.
